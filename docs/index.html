About CPU Cores

CPU Cores displays per-core CPU usage, memory, storage, hardware information, thermal state, uptime and widgets in a lightweight native interface.

System readings are processed locally on the device.

Highlights

  • Per-core CPU monitoring
  • Memory and storage overview
  • Hardware and thermal information
  • Home Screen and Lock Screen widgets
  • Open-source project
