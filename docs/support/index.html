How to open a GitHub Issue

All bug reports and technical questions are tracked publicly on GitHub. Please check existing issues first to avoid duplicates before creating a new one.

What to include in your report:

  • Device Model & iOS Version

    e.g., iPhone 13 Pro running iOS 16.5, or iPad Air (5th gen) on iPadOS 17.2.

  • Installation Method

    Specify whether you installed via AltStore PAL, standard sideloading (.ipa), or TrollStore (.tipa).

  • Environment Details

    If applicable, state your TrollStore version, jailbreak status, or signing tool.

  • Steps to Reproduce & Expected Behavior

    Clear step-by-step instructions leading to the issue, what you expected to see, and screenshots/screen recordings if helpful.

  • Reboot / Reinstall Check

    Confirm whether the issue persists after a clean device reboot or a fresh reinstall.
